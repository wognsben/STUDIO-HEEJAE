# STUDIO HEEJAE 텍스트 로고·3D 플립

2026-10-29 · 로컬 HOME/WORK 공통 헤더에 반영.

[제공 CodePen](https://codepen.io/petebarr/pen/oJvVpw)의 실제 코드를 읽고 3개 문자 레이어의 순차 X축 회전과 마지막 텍스트 정착 구조를 적용했습니다. 원본의 전체 화면 이동·마우스 추적·개발 도구는 가져오지 않았습니다.

- HTML 텍스트 STUDIO HEEJAE, Times New Roman/Times/serif, 검정. 링크는 HOME으로 연결됩니다.
- 기존 `.logo` 너비와 반응형 규칙을 유지합니다. 원본 PNG는 삭제하지 않았습니다.
- SplitText로 4개 레이어를 각각 12글자로 분리합니다. 시각 레이어는 aria-hidden이며 링크의 접근성 이름은 STUDIO HEEJAE 홈입니다.
- 3개 레이어는 각각 -90°→90°, 마지막 레이어는 -90°→0°. 각 레이어 시작은 0/.8/1.6/2.4초, 글자별 duration 1.6초, stagger .10초, power2.inOut입니다. 전체 약 5.1초이며 repeat를 사용하지 않습니다.
- perspective 700px, preserve-3d, backface-visibility hidden. Z축 깊이는 실제 로고 높이의 30%, 최대 14px로 제한했습니다. 18vw 및 viewport 너비 기반 깊이는 사용하지 않습니다.
- 평상시 마지막 텍스트만 표시. Hover/포커스 진입 시 재사용 timeline 재생. 완료·이탈 시 기본 텍스트로 복귀. 실행 중 진입 이벤트가 더 발생해도 timeline을 추가 생성하지 않습니다.
- ResizeObserver로 기존 로고 영역 너비에 맞춥니다. 재생 중 폭·헤더 높이·주변 메뉴는 변하지 않습니다.
- 언마운트 시 timeline.kill, SplitText.revert, 이벤트·ResizeObserver 정리. prefers-reduced-motion 매치 시 SplitText와 timeline을 만들지 않고 정적 텍스트를 유지하며 설정 변경도 수신합니다.

## 실제 검증

| 항목 | 결과 | 신뢰도 |
|---|---|---:|
| 기본 로고 | img 없음, 검정 HTML 텍스트, HOME 링크·접근성 이름 확인 | 0.99 |
| 실제 3D | 글자별 translate3d/rotateX와 700px perspective 실측. 단순 이동·opacity 대체 아님 | 0.98 |
| 다중 레이어 | 총 4개 레이어, 48개 분리 글자, 순차 회전과 정상 상태의 마지막 레이어만 표시 확인 | 0.98 |
| 폭·높이 | 1280px 뷰포트에서 로고 약 247.75×33.14px, x38.11. 재생·정지 동일. 헤더 높이 약114.34px | 0.98 |
| 완료·이탈 | 실행 중 running, 완료 후 idle 및 앞 3개 hidden/마지막 visible. 포커스 이탈 즉시 idle 확인 | 0.98 |
| 공통 헤더 | HOME Hover 및 WORK 키보드 Shift+Tab 진입/Tab 이탈 확인 | 0.97 |
| 모바일 | 390px에서 로고220×29.44px, x20~240, 메뉴 x315~355. 가로 넘침 없음 | 0.97 |
| 모션 감소 | 코드 경로·CSS 검토 완료. 브라우저 도구가 해당 설정 변경을 지원하지 않아 실제 환경 전환은 미검증 | 실증 완료에서 제외 |

폰트는 플랫폼별 시스템 세리프이므로 원본 이미지의 글꼴과 픽셀 단위로 동일하지 않습니다. 실제 화면에서 기본 상태를 확인했고, 가시적인 3D 변형과 요소의 overflow:visible도 확인했습니다. 모든 글자의 전체 프레임을 영상 녹화하여 검증한 것은 아닙니다. 글자 간 여러 3D 면이 겹쳐 보이는 것은 제공 원본의 다중 레이어 효과에 해당하며, 주변 메뉴와의 겹침은 관측하지 못했습니다.

구조·접근성 25%, 3D·복귀 45%, 레이아웃·모바일 30%를 가중한 확인 범위 신뢰도는 약 0.98입니다. 모션 감소 실제 환경 전환과 모든 중간 프레임 시각 검사는 이 수치에 포함하지 않았습니다.

TypeScript/Vite 빌드 성공. 브라우저 console error/warn 없음. 변경은 `Header.tsx`, 신규 `AnimatedLogo.tsx`·`AnimatedLogo.css`, GSAP 의존성 및 빌드 산출물에 한정됩니다. 그리드·영상 재생·보기 전환·페이지 전환 애니메이션은 수정하지 않았습니다.
