# STUDIO HEEJAE 전체 화면 메뉴

2026-10-29 · 로컬 사이트에 반영.

## 확인한 원인과 최소 변경

별도 Navigation 컴포넌트는 없으며 Header.tsx 안에 전체 화면 메뉴가 구현되어 있습니다. AnimatedLogo는 메뉴를 열어도 언마운트되지 않았지만, fixed·z-index100인 흰 패널이 뒤쪽 로고를 덮었습니다. 메뉴의 현재 페이지 판별 로직도 없었습니다.

- Header 전체 z-index는 auto로 유지하고, 메뉴 표시 중 기존 로고만 z-index101로 올렸습니다. Header의 초기 opacity 애니메이션이 별도 stacking context로 로고를 가두지 않도록 패널 표시 중 opacity1을 보장합니다.
- 로고는 계속 같은 위치에 한 개만 렌더합니다. AnimatedLogo 변경은 선택적 onNavigate 콜백과 링크 id에 한정되며 기존 GSAP/SplitText 코드·속도·글자·서체·크기는 수정하지 않았습니다.
- 로고 클릭은 HOME 이동과 메뉴 닫기를 함께 수행합니다. 닫기 애니메이션이 끝날 때까지 로고 레이어를 유지합니다.
- 데스크톱 메뉴 목록은 오른쪽45% 영역, 모바일에서는 기존 크기의 텍스트를 왼쪽에 재배치했습니다. 흰 배경·기존 열기/닫기 Motion 값은 그대로입니다.
- useLocation pathname으로 HOME, WORK 및 /work/ 하위, ABOUT, CONTACT를 판별합니다. 활성 항목은 aria-current=page 및 검정1.5px 밑줄입니다. 링크의 텍스트 너비만큼 적용됩니다. 미구현 ABOUT/CONTACT는 aria-disabled 상태와 준비 중 표시를 유지합니다.
- 메뉴가 열린 동안 콘텐츠·Footer와 헤더의 다른 메뉴/버튼은 inert로 차단합니다. 기존 로고는 dialog의 aria-owns로 연결하고 키보드 포커스 순환에 포함했습니다. 닫힌 후 배경 상태와 메뉴 열기 버튼 포커스를 복원합니다.
- 경로 변경 시 메뉴를 닫고 현재 페이지를 다시 판별합니다. 배경 클릭이나 뒤쪽 버튼의 키보드 접근을 허용하지 않습니다.
