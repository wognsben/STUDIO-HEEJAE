WORK 버튼의 화면 텍스트를 DOM에서 삭제했습니다. aria-label 및 aria-pressed는 유지합니다. 모든 상태 배경 투명, 선택 #111111 / 비선택 #AAAAAA, SVG fill=currentColor입니다. 사각형2개·4개와16:9는 그대로입니다. 키보드 Shift+Tab으로 버튼에 이동했을 때 focus-visible 및1px 검정 외곽선을 실측했습니다. 2열·4열 전환 후 실제컬럼수와 선택색을 확인했습니다. 모바일도 두 버튼의 투명 배경·선택색과 가로 넘침 없음을 확인했습니다.

변경은 global.css, Footer.css, WorkPage.tsx에 한정했습니다. 카테고리 필터·프로젝트 그리드·미디어·Header 로고·GSAP·Footer 워드마크 컴포넌트·정보는 변경하지 않았습니다. TypeScript/Vite 빌드 통과.
